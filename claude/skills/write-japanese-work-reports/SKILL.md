# 日本語の業務報告書を書く

## 内容を組み立てる

1. 読者、報告目的、指定様式、対象期間を、依頼と資料から読み取る。見本文書があれば、説明の細かさ、用語、文末の調子を合わせる。今回の事実は今回の資料から取る。
2. 作業メモから、実施したこと、確認できたこと、これから行うことを拾う。「この節を読んで何が分かればよいか」を一文にする。作業経過の節では、実施内容や現在の状況が要点になり得る。
3. 短い報告や一節の依頼なら、直接本文を書く。長い報告では、指定様式に沿って見出しと各節の要点を先に整理する。骨子の提示を求められた場合は、そこまでを返す。
4. 重要な事実が足りない場合は、書ける範囲で本文を作り、発注者の判断や次の作業に関わる確認事項だけを本文と分けて示す。本文に残す必要がある未確認事項は、何が未確認なのかを具体的に書く。

## 要点と根拠をつなぐ

- 節の冒頭で、読者が先に知りたいことを伝える。段落ごとに一つの話題を扱い、後続の文は、結果を支える事実、実施した方法、結果を受けた対応など、前の文との関係が分かる順に並べる。
- 評価や判断を書くときは、何を見てそう判断したかを本文からたどれるようにする。時系列や併記だけで示せる場合は、その関係をそのまま書く。「そのため」や「〜により」は、資料に因果関係が示されている場合に使う。
- 推敲では、まず各段落の要点を一文で言えるか、その要点を支える記述があるかを確認する。論点が混ざっていれば分け、同じ話題の短文が途切れていれば、共通の対象や前後関係が分かるようにまとめる。

## 評価は控えめに、行ったことは具体的に書く

- 作業は「何を、どうしたか」、結果は「何が分かったか」や「何ができるようになったか」で書く。評価の言葉で結果を飾らず、行ったことと見えたことを書く。「確認した」「表示を確認した」は、対応する行為が資料にあるときに使う。
- 断定や強い評価は、指示がなければ避ける。「全件」「問題なし」「原因を特定した」「大幅に向上した」のように範囲や効果を言い切る代わりに、確認した対象、手順、見つかったことを書く。実施予定、調査中の仮説、確認済みの結果は書き分ける。
- 控えめにするために「〜と思われる」「〜の可能性がある」を重ねない。言い切れる範囲まで対象を絞り、その範囲で起きたことをそのまま書く。
- 数値は、指定様式が求める場合と、進捗や対象範囲を示すのに要る場合に、資料の値を元の単位のまま使う。性能値や改善率のように評価に結びつく数値は、指示がなければ載せない。資料にない数値を計算して足さない。

## 自然な業務文に整える

- 文体は指定様式や見本に合わせ、指定がなければ文書内で揃える。読者が普段使う言葉と、対象や動作が分かる動詞を選ぶ。「確認を実施した」は「確認した」、「設定の見直しを行った」は「設定を見直した」で足りる。正確さに必要な専門用語は残し、読者に馴染みが薄い場合は最初に短く説明する。
- 一文には一つの事柄を書く。主語と述語を対応させ、誰が何をしたか、何がどうなったかを文の中で読み取れるようにする。
- 名詞を重ねた句は動詞で開く。「属性入力状況確認作業を実施した」は「属性の入力状況を確認した」と書く。
- 前置き、言い換えただけの繰り返し、情報を足さない定型句は省く。「適切に対応した」のような抽象的な評価は、実際の対応が分かるなら、その内容を書く。限定が必要なら、分かっている対象や条件を添える。
- 比喩、誇張、キャッチコピー調の言い回しを使わない。「大きな一歩となった」「劇的に改善した」「シームレスな連携を実現した」のような文は、何をして何が変わったかに置き換える。
- 手垢のついた表現（「鋭意」「万全を期す」「円滑に」「〜を図った」「〜に寄与した」「〜に努めた」）は、具体的な行為か結果に置き換える。置き換える中身が資料になければ削る。
- 下書きの推敲では、元の意味と時制を保ち、判断を元より強めない。作業メモもある場合は照合し、判断に関わる食い違いを示す。仕上げに、元資料にない成果や約束を加えていないか確かめる。

## 書き分けの例

| 作業メモ | 報告文 |
| --- | --- |
| 更新分について座標参照系と必須属性の入力状況を見た。合否判定の記録はない。 | 更新したデータについて、座標参照系と必須属性の入力状況を確認した。 |
| 確認状況の一覧を追加。データごとにステータスが見える。 | データごとの確認状況を一覧で見られるようにした。 |
| 調べたケースでは旧設定が残っていた。設定を変更して同じ手順で動作を確認した。 | 確認したケースでは、更新前の設定が残っていた。設定を見直し、同じ手順で動作を確認した。 |
| 更新した地物を地図で確認。一部に位置のずれ。該当箇所は反映を保留し、次回は元データと照合する。 | 更新した地物を地図上で確認したところ、一部で位置のずれが見つかった。該当箇所は反映を保留しており、次回、元データと照合する。 |
