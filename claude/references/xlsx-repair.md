# 編集前から壊れていた.xlsxの直し方

`xlsx-guard`（`~/.claude/hooks/xlsx-guard.py`）がエラーを出し、そのエラーが今回の編集より前からファイルにあった場合の手順。編集で壊したのなら、この手順ではなく、編集前のバックアップに戻してやり直す。

## 前から壊れていたかを確かめる

- 編集前のバックアップに`python3 -I ~/.claude/hooks/xlsx_validate.py <バックアップ>`をかけ、同じエラーが出るかを見る。
- 出なければ、今回の編集で壊している。バックアップに戻す。
- 出れば、以下の手順に進む。ユーザーには、前から壊れていたことと、Excelで開くと修復のダイアログが出ていたはずであることを伝える。

## 手順

1. **本物を退避する。** 同じフォルダの`bk/<日時>_<作業名>/`にコピーし、SHA-256が一致することを確かめる。
2. **Excelに修復させたコピーを作ってもらう。** 本物には触れず、コピー（編集前のバックアップのコピーでよい）をExcelで開いてもらう。修復のダイアログで「はい」を押し、別名で保存してもらう。
   - Mac版Excelは、修復した内容の一覧を出さないことがある。一覧がなくても次に進める。
   - 保存先は、ユーザーに聞いて確かめる（既定の保存先がダウンロードフォルダなどになっていることがある）。
   - Excelの画面は、Claudeからは自動では読めない（補助アクセスがない）。ダイアログが出たかどうかは、ユーザーに聞く。
3. **修復前と修復後を部品ごとに比べる。** zipの各部品（`xl/worksheets/*.xml`、`xl/sharedStrings.xml`、`[Content_Types].xml`、`*.rels`など）の有無と中身の差を見て、Excelが直した箇所を特定する。
   - 保存場所の記録（`workbook.xml`の`absPath`）、更新日時（`docProps/core.xml`）、`revisionPtr`、`fileRecoveryPr`は、修復と関係なく変わる。無視してよい。
   - 条件付き書式の`sqref`の並び順だけが変わることがある。範囲の集合が同じなら無視してよい。
4. **本物で、特定した箇所だけを同じように直す。** 修復版で本物を置き換えない（今回の編集分が修復版に入っていないことがあるため。また、修復でデータが消えていることがあるため）。
   - 直したあと、全セルの値・数式・書式・列幅・行高が直す前と一致することを確かめる。
   - `xlsx_validate.py`でエラーが出ないことを確かめる。警告は、修復のきっかけになるとは確かめられていないものなので、残すか取り除くかを判断し、その判断を`evidence.md`に書く。
5. **Excelで開いてもらう。** 修復のダイアログが出ないことを、ユーザーに確かめてもらう。修復させたコピーは、もう要らないことを伝える。
6. 原因、直した箇所、バックアップの場所、確かめたことを`evidence.md`に残す。

## 壊れ方ごとの直し方

### ふりがな（`<rPh>`）の範囲の重なり・はみ出し

- 共有文字列（`xl/sharedStrings.xml`）の`<si>`の中で、`<rPh sb=".." eb="..">`の範囲が重なっている、または文字列の長さを超えている。日本語入力（IME）で入力したときに、Excel自身が壊れたふりがなを書き込むことがある。
- 直し方：エラーになった`<rPh>`（範囲が重なる・はみ出す）だけを取り除く。重なった組は、両方とも取り除いてよい。セルの表示は変わらない。
- 警告になった`<rPh>`（中身が空、制御文字を含む）は、エラーと同じ文字列にあれば一緒に取り除いてよい。別の文字列にあるだけなら、残してよい。Excelは開いたときに修復せず、次に保存するときに黙って片付けることがある。
- 2026/10/16の例：WBSの2.2.2の進捗状況（共有文字列#432）で、同じ位置（sb=244, eb=246）に制御文字だけのふりがなが2つ重なっていた。Excelは修復のとき2つを1つにまとめた。こちらでは、重なった2つと、同じ文字列の空の1つを取り除いた。別の文字列（#449）にも制御文字入りのふりがなが残っていたが、修復のダイアログは出ず、Excelが次の自動保存で片付けた。

### 中身が空の人物リスト（`xl/persons/person.xml`）

- スレッド形式のコメント用の部品。コメントがないのに残っていることがある。修復のきっかけになるかは確かめていない。ただ、Excelが修復のときに部品ごと削除したことがある。
- ふりがなと一緒に見つかったら、部品と、`xl/_rels/workbook.xml.rels`の関連付け、`[Content_Types].xml`の`Override`をあわせて取り除く。
